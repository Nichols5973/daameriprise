# columns-promo

Custom **columns** block. Purpose: promo-split-card.

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one row with two cells: an image cell and a text cell
(optional eyebrow paragraph, heading, paragraph(s), CTA link). Either cell may come first;
desktop layout follows authored order, mobile always shows the image on top.

## Supported variations

| Variation | Option class | Effect |
| --- | --- | --- |
| Default | - | Stone card (`--color-amp-stone`), bold navy heading |
| Purple | `purple` | Light purple card (`--color-amp-purple-light`), regular-weight neutral heading |
